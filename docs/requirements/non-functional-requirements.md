# Non-Functional Requirements

> Requisitos no funcionales obligatorios de la versión actual de GorilaType: bajo qué condiciones y con qué calidad debe operar el sistema.

**Última actualización:** 2026-07-16
**Autor(es):** Equipo GorilaType

---

## 1. Requisitos no funcionales obligatorios

| ID | Nombre | Descripción |
|---|---|---|
| RNF-01 | Rendimiento | El sistema debe responder en menos de 2 segundos. |
| RNF-02 | Seguridad | Autenticación segura de usuarios. |
| RNF-03 | Usabilidad | Interfaz clara e intuitiva. |
| RNF-04 | Baja latencia | Respuesta inmediata al escribir. |
| RNF-05 | Compatibilidad escritorio | Adaptado a diferentes tamaños de pantalla en escritorio. |
| RNF-06 | Latencia del teclado | Tiempo de respuesta menor a 50 ms. |
| RNF-07 | Precisión de cálculos | Exactitud en WPM y precisión. |

> Los requisitos no funcionales planificados para versiones futuras están documentados por separado en [`future-requirements.md`](./future-requirements.md).
