# GT-09 – Onboarding y Tutorial Inicial

> Introducción guiada para usuarios nuevos sobre el funcionamiento de la plataforma.

**Última actualización:** 2026-08-04
**Autor(es):** Marcelo Llanos

---

## Historia

**Como** usuario nuevo  
**Quiero** ver una breve guía de cómo funciona la plataforma  
**Para** entender cómo realizar mi primera prueba sin confusión

---

## Detalles Generales

- **ID:** GT-09
- **Tiempo estimado:** 1.5 días
- **Story Points:** 5
- **Prioridad:** Baja

---

## Criterios de aceptación

- Se muestra un tutorial u onboarding la primera vez que el usuario ingresa a la plataforma.
- El usuario tiene la opción de omitir (saltar) el tutorial en cualquier momento.
- El tutorial explica de forma clara cómo iniciar una prueba y la ubicación de los indicadores de resultados.
- El sistema registra que el usuario ya vio el tutorial para que no vuelva a mostrarse automáticamente en sesiones posteriores.
