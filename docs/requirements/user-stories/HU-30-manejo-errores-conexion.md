# HU-30 – Manejo de Errores de Conexión

> Comportamiento del sistema ante fallas de red durante el uso de la plataforma.

**Última actualización:** 2026-07-29
**Autor(es):** Marcelo Llanos

---

## Historia

**Como** usuario

**Quiero** recibir aviso claro cuando pierdo conexión

**Para** no perder mis resultados ni quedar confundido sobre el estado de la prueba

## Detalles

- **ID:** HU-30
- **Tiempo estimado:** 1.5 días
- **Story Points:** 5
- **Prioridad:** Media

## Criterios de aceptación

- Se muestra un mensaje visible cuando se pierde la conexión.
- Si falla el guardado de un resultado, el sistema reintenta o informa al usuario.
- El usuario puede continuar escribiendo localmente aunque la conexión falle momentáneamente.
- No se pierden resultados de pruebas ya finalizadas por errores de red.
