# HU-27 – Cierre de Sesión

> Cierre explícito de sesión por parte del usuario.

**Última actualización:** 2026-07-29
**Autor(es):** Marcelo Llanos

---

## Historia

**Como** usuario

**Quiero** cerrar sesión de forma explícita

**Para** proteger mi cuenta cuando uso un dispositivo compartido

## Detalles

- **ID:** HU-27
- **Tiempo estimado:** 0.5 días
- **Story Points:** 2
- **Prioridad:** Alta

## Criterios de aceptación

- Existe una opción visible de "Cerrar sesión".
- Al cerrar sesión se invalida el token/sesión activa.
- El usuario es redirigido a la pantalla de inicio de sesión.
- No queda información de sesión accesible tras el cierre.
