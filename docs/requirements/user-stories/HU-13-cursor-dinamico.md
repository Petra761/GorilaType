**Autor(es):** Marcelo Llanos

---

## Historia

**Como** usuario

**Quiero** que el cursor avance automáticamente

**Para** seguir el flujo de escritura

## Detalles

- **ID:** HU-13

## Criterios de aceptación

- El cursor se mueve al siguiente carácter automáticamente.
- El usuario no puede saltar posiciones manualmente.
- El cursor coincide con la posición actual.
