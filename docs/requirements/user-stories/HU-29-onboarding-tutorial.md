# HU-29 – Onboarding y Tutorial Inicial

> Introducción guiada para usuarios nuevos sobre el funcionamiento de la plataforma.

**Última actualización:** 2026-07-29
**Autor(es):** Marcelo Llanos

---

## Historia

**Como** usuario nuevo

**Quiero** ver una breve guía de cómo funciona la plataforma

**Para** entender cómo realizar mi primera prueba sin confusión

## Detalles

- **ID:** HU-29
- **Tiempo estimado:** 1.5 días
- **Story Points:** 5
- **Prioridad:** Baja

## Criterios de aceptación

- Se muestra un tutorial u onboarding la primera vez que el usuario ingresa.
- El usuario puede omitir el tutorial en cualquier momento.
- El tutorial explica cómo iniciar una prueba y dónde ver los resultados.
- El tutorial no vuelve a mostrarse automáticamente en sesiones posteriores.
