# Future Requirements

> Requisitos funcionales y no funcionales planificados para versiones futuras de GorilaType, incluyendo aquellos considerados opcionales. Ninguno de estos forma parte del compromiso de la versión actual (ver [`functional-requirements.md`](./functional-requirements.md) y [`non-functional-requirements.md`](./non-functional-requirements.md)).

**Última actualización:** 2026-07-16
**Autor(es):** Equipo GorilaType

---

## 1. Requisitos funcionales futuros

| ID | Nombre | Descripción |
|---|---|---|
| RFF-01 | Onboarding inicial | Mostrar guía para nuevos usuarios. |
| RFF-02 | Sistema de amigos | Permitir agregar y gestionar amigos. |
| RFF-03 | Retos entre amigos | Competencias entre usuarios. |
| RFF-04 | Chat entre amigos | Comunicación entre usuarios. |
| RFF-05 | Modo aprendizaje | Sugerencias basadas en errores. |

## 2. Requisitos funcionales opcionales

|---|---|---|

## 3. Requisitos no funcionales futuros

| ID | Nombre | Descripción |
|---|---|---|
| RNFF-01 | Testing | Implementación de pruebas automatizadas. |

| RNFF-03 | Logs del sistema | Registro de eventos y errores. |
